# 📚 RAG Manual Assistant ### Consulta inteligente sobre documentación técnica y manuales en PDF Aplicación Full Stack desarrollada para indexar y consultar manuales técnicos mediante una arquitectura **RAG (Retrieval-Augmented Generation)**, combinando un backend de alto rendimiento en **Python y FastAPI** con una interfaz moderna en **React**. # 🚀 Probar la aplicación Puedes clonar el repositorio y levantar el entorno localmente para comenzar a consultar tu propia documentación técnica. > **Nota:** El sistema requiere tener en marcha tanto el servidor backend de FastAPI como el entorno de desarrollo del frontend.
     
--- ## 📑 Índice - [Objetivo del proyecto](#-objetivo-del-proyecto) - [Arquitectura](#️-arquitectura) - [Tecnologías](#-tecnologías) - [Estructura del proyecto](#-estructura-del-proyecto) - [Instalación](#-instalación) - [Decisiones de diseño](#-decisiones-de-diseño) # 🎯 Objetivo del proyecto La documentación técnica suele ser extensa, densa y difícil de consultar con rapidez mediante búsquedas tradicionales por palabras clave. Este proyecto nace para resolver ese problema aplicando una arquitectura **RAG**. En lugar de depender de búsquedas exactas, el sistema procesa manuales en formato PDF, genera embeddings vectoriales y permite realizar preguntas en lenguaje natural obteniendo respuestas precisas basadas estrictamente en el contenido de los documentos cargados. --- # 🏗️ Arquitectura La aplicación sigue una arquitectura desacoplada estructurada en dos capas principales: ```mermaid flowchart LR A["👤 Usuario"] --> B["⚛️ React (Frontend)"] B --> C["⚡ FastAPI (Backend REST)"] C --> D["📄 Procesamiento de PDFs"] D --> E["🧠 Motor RAG & Embeddings"] E --> C C --> B B --> A ``` Esta separación permite gestionar la ingesta de documentos y las consultas conversacionales de forma aislada, manteniendo el rendimiento y la escalabilidad del sistema. # 🚀 Características ✔ Carga e indexación automática de manuales en formato PDF. ✔ Consulta conversacional inteligente basada en recuperación de contexto. ✔ Interfaz moderna con componentes modulares desarrollada en React y Vite. ✔ Panel lateral con control del estado del backend, subida de ficheros y listado de manuales. ✔ Diseño adaptativo (*responsive*) optimizado para múltiples dispositivos. # 📦 Estructura del proyecto ```text RAG-MVP/ │ ├── backend/ │ ├── server_fastapi.py # Servidor y endpoints de la API REST │ ├── ingest.py # Lógica de procesamiento y vectorización de PDFs │ ├── query.py # Motor de recuperación y consultas RAG │ ├── config.py # Configuración de rutas y variables │ └── requirements.txt # Dependencias de Python │ ├── frontend/ │ ├── src/ │ │ ├── api/ # Conexión con el backend │ │ ├── components/ # Componentes modulares (Chat, Status, ManualList, UploadManual) │ │ ├── styles/ # Hojas de estilos personalizadas (App.css, theme.css) │ │ ├── App.jsx # Componente raíz de la aplicación │ │ └── main.jsx # Punto de montaje de React │ ├── package.json │ └── vite.config.js │ └── .gitignore ``` # ⚙️ Instalación y ejecución Sigue estos pasos para poner en marcha el proyecto en tu entorno local: ### 1. Clonar el repositorio ```bash git clone https://github.com/Deve-Lopez/RAG-MVP.git cd RAG-MVP ``` ### 2. Configurar y arrancar el Backend ```bash cd backend python -m venv .venv # Activar el entorno virtual: # En Windows (PowerShell/CMD): .venv\Scripts\activate # En macOS / Linux: source .venv/bin/activate # Instalar dependencias y ejecutar el servidor pip install -r requirements.txt uvicorn server_fastapi.py --host 0.0.0.0 --port 8000 ``` ### 3. Configurar y arrancar el Frontend Abre una **nueva pestaña o ventana en tu terminal**, dirígete a la carpeta del frontend y arranca el servidor de desarrollo: ```bash cd frontend npm install npm run dev ``` Una vez ejecutado, abre tu navegador e ingresa a la URL proporcionada por Vite (por defecto: `http://localhost:5173`). # 🧠 Decisiones de diseño | Decisión | Motivo | |----------|--------| | **React + Vite** | Desarrollo rápido, modular y con una excelente experiencia de usuario en el cliente. | | **FastAPI** | Permite construir una API REST rápida, tipada y con soporte asíncrono ideal para pipelines de IA. | | **Arquitectura RAG** | Garantiza que las respuestas del asistente estén contextualizadas en la documentación técnica real aportada. | | **Bootstrap + Custom CSS** | Estilos modulares combinados con variables globales para un diseño limpio y adaptativo. |
